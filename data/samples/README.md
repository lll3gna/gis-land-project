# Sample data

Файлы в этой папке — синтетические данные для автоматической проверки pipeline. Оба файла описывают **одно и то же место**, поэтому на них проверяется стыковка кадастра и снимка.

- `vok104_boundary.geojson` — синтетический участок ≈10 соток (заявлено 1000 м², по геометрии ≈994 м²) с кадастровым номером, площадью, категорией земель и разрешённым использованием.
- `vok104_imagery.tif` — 3-канальный 16-битный GeoTIFF 125×126 px в EPSG:32637 (UTM 37N), 0,5 м/пиксель, RGB ColorInterp, nodata=0 (рамка 6 px по краю). Покрывает участок с запасом 15 м; внутри участка нарисованы «дом» и «дорожка».

Файлы генерируются скриптом без внешних зависимостей:

```bash
python tools/make_sample_data.py
```

Это не реальная кадастровая выписка и не спутниковый снимок VOK-104: данные нужны только для воспроизводимого запуска тестов.
