# Sample data

Файлы в этой папке — маленькие синтетические данные для автоматической проверки pipeline.

- `vok104_boundary.geojson` — синтетический Polygon с кадастровым номером и площадью.
- `vok104_imagery.tif` — валидный 3-band GeoTIFF с CRS EPSG:32637, nodata=0 и RGB ColorInterp.

Эти файлы не являются реальной кадастровой выпиской или спутниковым снимком VOK-104 и используются только для воспроизводимого запуска тестов.
