# Единая схема данных участка (VOK-104)

## 1. Основные идентификаторы
* **Кадастровый номер:** `строка (например, 50:11:0000000:XXXX)`
* **Система координат:** `WGS 84 / EPSG:4326` (или укажи вашу рабочую, например, МСК-50)

## 2. Геометрия и контуры
* **Контур участка:** `GeoJSON Polygon / Multipolygon`
* **Атрибуты участка:** `площадь, категория земель, разрешенное использование`

## 3. Данные снимков и распознавания (Imagery & Segmentation)
* **Исходный снимок:** `путь к файлу .tif / .png`
* **Имена файлов:** `Формат: YYYY-MM-DD_vok104_cadastre.png`
* **Найденные объекты (Классы):**
  1. `building` (здания/строения)
  2. `vegetation` (древесно-кустарниковая растительность)
  3. `water_body` (водоемы)
  4. `road` (дороги/подъезды)
