# Поставщики контуров участков (вместо прямого доступа к НСПД)

Дата: 7 октября 2026 · Контекст: [docs/nspd-spike.md](nspd-spike.md) — открытого программного доступа к НСПД нет.

Вопрос: **кто по кадастровому номеру отдаёт именно контур участка (полигон с координатами), а не только номер, площадь или точку?**

Сведения ниже — по документации и сайтам поставщиков на 07.10.2026. Земеля проверена реальными запросами — см. «Результат проверки Земели»; остальные — только по документации.

## Сравнение

## Важные оговорки

- **Источник данных.** Почти все агрегаторы берут контуры из того же НСПД/ЕГРН. Перед подключением нужно прочитать их оферту: разрешено ли **коммерческое использование и показ контуров нашим пользователям**, а не только «для себя».
- **Участки без границ в ЕГРН** (как 50:11:0050507:130) не даст ни один поставщик: координат нет в самом реестре. Для них в Абрисе всё равно нужна ручная обводка.
- **Лимит Земели 10 запросов/мин** хватит для пилота, но для продукта нужен кэш полученных контуров и, возможно, тариф выше.

Итог по 7 реальным участкам: 6 контуров получены и сходятся с НСПД, 1 участок без границ в ЕГРН вернул точку-центр — как и ожидалось.

Наблюдения:

- **Сбой шлюза при опросе** (HTTP 504) не означает сбой задачи: результат лежит на сервере и забирается по `request_id` без нового платного запроса (`tools/zemelya_probe.py --job CAD_NUM REQUEST_ID`; скрипт теперь сам повторяет опрос при ответах 5xx). В продукте нужен такой же повтор.
- **Контур приходит и сразу подходит под контракт проекта** (`read_cadastre` принимает без доработок).
- **Скорость:** 36–91 с на участок вместо заявленных ~1,4 с; синхронный запрос с таймаутом 60 с обрывался, поэтому используем асинхронный метод. Для продукта нужны индикатор ожидания и кэш полученных контуров.
- **Участок без границ:** приходит точка-центр — пригодится, чтобы сразу показать нужное место на экране ручной обводки. Площадь в этом случае брать из `declared_area`.
- **Лишние данные:** вместе с запрошенными `area_data` и `area_geometry` пришли `area_restrictions` (номер и дата регистрации права), `area_surroundings`, `area_gis_ogd_mosobl`. ФИО собственников нет. Нам эти наборы не нужны — не хранить и попросить отключить.

Ответы Земели на вопросы (письма 07.10.2026):

| Вопрос | Ответ |
|---|---|
| Списываются ли запросы по участкам без границ (`no_coords`) | Да, списываются |
| Если НСПД недоступен | Ответ с ошибкой получения данных, запрос **не** списывается |
| Можно ли показывать контуры пользователям и хранить у себя | «Можете использовать без ограничений» (письменно, по e-mail) |
| Договор с физлицом | Можно, нужен договор, желательна электронная подпись |
| Источник геометрии | НСПД, данные получаются онлайн в момент запроса |
| Цена | индивидуально, после пилота — в зависимости от объёма и набора полей |

**Вывод:** Земеля подходит как источник контуров для пилота. Зависимость от НСПД сохраняется (источник — НСПД онлайн), поэтому ручная обводка в продукте остаётся обязательной.

## Как проверить (Земеля)

Скрипт: [`tools/zemelya_probe.py`](../tools/zemelya_probe.py).

1. Получить токен у Земели (тестовый ключ) и записать в `.env`: `ZEMELYA_TOKEN=...` (`.env` не попадает в git).
2. `python tools/zemelya_probe.py` — демо-номер из документации, запросы не списываются.
3. `python tools/zemelya_probe.py --real` — три наших участка. Ожидаем:
   - 28236 и 28641 — контур есть, `read_cadastre` проходит, площадь сходится с НСПД (600 и 800 м²);
   - 50507:130 — `no_coords: true`, контура нет.
4. Если контур пришёл — сравнить его с контуром на скриншоте НСПД ([docs/nspd/](nspd/)).
5. Запросить у Земели цену за пакет на 1000 запросов и условия коммерческого использования.
