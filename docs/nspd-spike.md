# Спайк: можно ли программно получить границы участка из НСПД

Дата: 7 октября 2026 · Проверяли: Анна Соловьева (с помощью Claude) · Скрипт: [`tools/nspd_probe.py`](../tools/nspd_probe.py)

## Вопрос

Можем ли мы с российского IP автоматически, по кадастровому номеру, получить из НСПД контур участка, площадь, категорию земель и вид разрешённого использования?

## Как проверяли

1. **Вручную в браузере** (Chrome, российский IP, сертификат Минцифры установлен): три реальных участка найдены по номеру, карточки сохранены в [`docs/nspd/`](nspd/).
2. **Скриптом** `tools/nspd_probe.py` с того же компьютера, российский IP (Москва, провайдер Avantel, подтверждено через ipinfo.io). TLS-проверка включена, сертификат Минцифры берётся из системной связки ключей (`truststore`). Обычные HTTP-запросы без маскировки под браузер, пауза 2 с между запросами, всего 6 запросов к НСПД.

## Результат

| Канал | Адрес | Результат | Вывод |
|---|---|---|---|
| Сайт НСПД (браузер) | nspd.gov.ru/map | работает; в ночь на 7.10 поиск выдавал ошибку, утром 7.10 — работает | человеку доступно |
| Главная страница (скрипт) | `https://nspd.gov.ru/` | **200** | сайт с российского IP доступен |
| Официальный WFS (Росреестр) | `https://nspd.rosreestr.gov.ru/api/wfs/v2?...GetCapabilities` | **SSLError**: «NSPD: Self-signed certificate» is not trusted | сервис на самоподписанном сертификате, для публичного использования не предназначен; проверку сертификата не отключали |
| WFS на домене НСПД (скрипт) | `https://nspd.gov.ru/api/wfs/v2?...GetCapabilities` | **403 Forbidden** | закрыт |
| Поиск участка API веб-карты (скрипт) | `https://nspd.gov.ru/api/geoportal/v2/search/geoportal?thematicSearchId=1&query=…` | **403 Forbidden** для всех трёх номеров, ответ за 0,04–0,18 с | запросы программ отсекаются защитой (WAF) |

Отказы 403 выдаёт WAF НСПД. Важно, что срабатывают **разные правила**:

- с зарубежного IP (через VPN) — правило `6644b4542eea83526555e4b5`: блокировка по стране, закрыт весь сайт;
- с российского IP для программного запроса — правило `68b94cb96faa4b9f4c8e0e79`: главная страница при этом открывается, закрыты только API.

То есть НСПД целенаправленно пропускает браузер и отсекает автоматические запросы к данным.

## Наблюдения по данным

- Карта НСПД работает в проекции **EPSG:3857** (координаты в адресной строке — метры веб-Меркатора).
- У участка **50:11:0050507:130** в ЕГРН **нет координат границ** («Без координат границ», площадь декларированная, статус «ранее учтённый»). Даже при доступе к API контур для таких участков получить нельзя.

## Вывод

**Открытого программного канала получения границ из НСПД нет.** Официальный WFS не готов к публичному использованию (самоподписанный сертификат), а API веб-карты закрыт для программ. Обходить защиту (подделывать запросы под браузер, отключать проверку сертификатов) мы не стали и не планируем: это нарушает правила доступа и ненадёжно для продукта.

## Что это значит для MVP

Строить автоматическое получение контура на НСПД нельзя. Варианты, от быстрых к надёжным:

1. **Пользователь сам обводит границу** на спутниковом снимке (подсказка: точка участка по адресу/номеру). Нужен в любом случае — для участков без границ в ЕГРН.
2. **Загрузка межевого плана или выписки ЕГРН** (XML Росреестра содержит координаты границ) — для пользователей, у которых документы есть.
3. **Платный API-агрегатор** (Реестр API, api-kadastr и др. из [сравнения источников](data-sources-comparison.md)) — проверить, отдают ли они именно **геометрию** границ, а не только атрибуты, и на каких условиях коммерческого использования.
4. **Официальный запрос в Роскадастр (ППК «Роскадастр») / Росреестр** о порядке доступа к WFS НСПД для юрлиц или разработчиков — долгий путь, но единственный «чистый» для продукта на подписке.
