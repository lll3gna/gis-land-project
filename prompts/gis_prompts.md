# Промпты для Codex (Спринт 2–15 окт)

В данном файле собраны и зафиксированы инструкции, которые использовались для генерации базовых скриптов ГИС-анализа участка VOK-104.

## 1. Скрипт чтения кадастровых данных (cadastre/read_cadastre.py)
* **Промпт:** "Напиши базовый Python-скрипт read_cadastre.py, который загружает кадастровые границы участка VOK-104 из GeoJSON-файла, извлекает его геометрию и выводит в консоль ключевые атрибуты: кадастровый номер и площадь участка. Код должен быть чистым, с обработкой ошибок и комментариями."

## 2. Скрипт обработки снимков (imagery/process_imagery.py)
* **Промпт:** "Напиши Python-скрипт process_imagery.py для папки imagery/, который обрабатывает спутниковый снимок участка VOK-104. Использовать библиотеку rasterio для работы с геотиффами или PIL/OpenCV для PNG. Перепроецируй снимок к единой системе координат проекта WGS 84 (EPSG:4326) и подготовь картинку для модуля сегментации: нормализуй разрешение и сохрани результат в data/samples/ready_for_segmentation.png."
